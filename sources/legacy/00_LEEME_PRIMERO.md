# EMPIEZA AQUÍ - Paquete maestro CETPRO
Este ZIP contiene instrucciones de construcción y guías. No contiene un libro terminado ni acredita módulos aprobados.

## Tu primera conversación
1. Descarga y conserva este ZIP completo.
2. Abre una conversación nueva con Sol o Codex y adjunta este mismo ZIP.
3. Copia todo el texto de 02_INICIAR_M00.txt y envíalo. BD.zip y CARRERAS.jpeg ya están incluidos como fuentes originales.
4. Si tienes las 21 plantillas oficiales corregidas, adjunta también su ZIP original. Si faltan, el modelo debe inventariar el pendiente y continuar los contratos independientes.
5. Descarga ENTREGA_M00.zip. Lee su resumen y bloqueos. Si propone decisiones institucionales, responde con el documento o dato real. No apruebes supuestos como datos confirmados.
6. Para M01 abre otro chat, adjunta este paquete y ENTREGA_M00.zip aprobada; copia 04_MODULOS/M01/PROMPT.txt. Repite con el módulo siguiente solo cuando la puerta anterior esté satisfecha.

## En cada paso
Una conversación ejecuta un módulo. M12 tiene 13 conectores: puedes repartirlos en subconversaciones usando los prompts individuales y llevando siempre la entrega acumulada más reciente. No mezcles dos ramas de libros. El cierre de M12 exige los trece.
Cada módulo tiene PROMPT.txt y ADJUNTAR.md. Adjunta los archivos indicados. Los datos o formatos adicionales se incorporan a FUENTES de la entrega; en el siguiente chat bastan el paquete de instrucciones y el último ZIP acumulativo, si ya contiene las fuentes necesarias.
No uses ENTREGA_Mxx como base aprobada solo por su nombre: revisa ESTADO_ACTUAL.md. Un candidato con pruebas pendientes se lleva al prompt de pruebas o corrección del mismo módulo.

## Los tres archivos que siempre debes conservar
Paquete maestro de instrucciones; última entrega APROBADA; último CANDIDATO si existe. Conserva también tus fuentes originales. Nunca reemplaces la entrega aprobada por una corrección sin revisar su resultado.

## Semáforo del proyecto
PENDIENTE: no iniciado. EN_CURSO: construcción. BLOQUEADO: falta entrada/decisión. PENDIENTE_EXCEL: necesita ejecución real. EN_REVISION: listo para revisión. APROBADO: puerta satisfecha con evidencias. No hay módulos aprobados al entregar este paquete.
Consulta 03_CONTROL/TABLERO.html y ESTADO_MODULOS.csv. El modelo debe regenerarlos al terminar cada módulo; el tablero del paquete es la fotografía inicial.

## Qué falta conseguir
Las 21 plantillas oficiales Excel; catálogo curricular oficial con unidades, capacidades, indicadores, actividades, créditos y horas; reglas de evaluación, recuperación, asistencia, EFSRT, cierre y título; periodo y módulo de cada grupo; datos institucionales, docentes y firmas autorizadas. La fotografía solo sirve para catálogo provisional.
Se puede iniciar M00 hoy. Las dependencias bloqueadas no impiden documentar otros pendientes; sí impiden aprobar o integrar su funcionalidad como terminada.
