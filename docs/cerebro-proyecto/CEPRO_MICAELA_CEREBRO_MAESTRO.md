## 1. Misión y alcance

Modernizar un sistema de gestión académica de CETPRO a una aplicación Windows **offline-first**, manteniendo reglas institucionales canónicas y sin pérdida de información. Arquitectura actual reportada: **React 19, TypeScript, Tailwind CSS, Vite, Electron, Node.js 24, `node:sqlite`/`DatabaseSync`, backend HTTP local y SQLite WAL**. Roles: **DIRECTOR, SECRETARIA, DOCENTE**. Incluye sincronización USB `.cetpro`, admisión con ficha de registro de datos 2026 (QR Inverso / WhatsApp Web / formulario autónomo HTML), emisión de documentos institucionales y respaldo/restauración cifrada `.cetpro-backup`.
