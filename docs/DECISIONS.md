## D-018: Validación Real UX como Criterio de Aceptación
**Fecha:** 2026-09-14
**Contexto:** Se detectó que el módulo M11 (Nómina PDF) estaba funcionalmente aprobado a nivel de tests y en una POC técnica independiente, pero la Secretaria (usuaria final) seguía viendo el renderizador legado en la interfaz principal.
**Decisión:** Ningún módulo, componente documental o función se considera cerrado si solo funciona en POC, script, test o página técnica independiente. Antes del cierre definitivo de una historia, debe existir integración funcional validada en la interfaz principal que utilizará la secretaria (Ej. #/documentos).
**Consecuencia:** El motor PDF nativo debe exponerse mediante un iframe (Blob application/pdf) integrado orgánicamente en DocumentsView. Esto aplicará obligatoriamente a M12 y subsiguientes.
